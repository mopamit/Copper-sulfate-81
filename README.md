# סימולציית נחושת וגופרית

החבילה מוכנה לפרסום ב-GitHub Pages.

## העלאה

1. העלו את `index.html` ואת `prismind-logo.png` לאותה תיקייה במאגר.
2. ב-GitHub פתחו `Settings` > `Pages`.
3. בחרו `Deploy from a branch`, את הענף `main` ואת התיקייה `/root`.

אין צורך בתהליך build או בהתקנת ספריות.

## הערה מדעית

הניסוי מדגים יצירת נחושת גופרית (Copper sulfide) מחימום נחושת וגופרית. נחושת גופרתית (Copper sulfate) היא חומר אחר.
